# Fractal Play

This is an app for generating simple Iterated Function System (IFS) fractals and allowing their parameters to be played
with dynamically.

It runs in the browser and is written in Elm.

## Setup

Install Node.js dependencies:

```bash
npm install
```

## Development

### Build the app

```bash
npm run build
```

### Run tests

```bash
npm test
```

### Preview the built app

```bash
npm run preview
```

Then open your browser to the URL shown (typically `http://localhost:8080`).

### Development with Elm Reactor

For development with hot reloading:

```bash
npm run reactor
```

Then go to `http://localhost:8000` and navigate to your source files.
